# fixed-cairo

`fixed`: a signed Q32.32 fixed-point scalar for [Cairo](https://www.cairo-lang.org),
deterministic and gas-efficient: `Fixed { raw: i64 }`, fused kernels that rescale once per output
(`fixed::wide`), and loop-free transcendental functions (`fixed::trig`, `fixed::exp`). Zero
dependencies.

It is the common foundation of the Cairo ports of the Rust game-physics stack:
[`glam-cairo`](https://github.com/bal7hazar/glam-cairo) (`glam`),
[`glamx-cairo`](https://github.com/bal7hazar/glamx-cairo) (`glamx`), `nalgebra-cairo` and
`rapier-cairo`. It has no Rust counterpart repository (`f64` is a language primitive); it was
split out of `glam-cairo` with its full history, and releases 0.1.0 to 0.3.0 were published from
there.

## Install

```toml
[dependencies]
fixed = "0.3.0"
```

```cairo
use fixed::{Fixed, FixedTrait, HALF, TrigTrait};

let a: Fixed = 3_i32.into();
let b = FixedTrait::from_ratio(1, 3);        // 1/3, rounded to nearest
let c = a * b + HALF;                        // `*` floors, `+` is a native i64 add
let (s, co) = c.sin_cos();
```

API, rounding and overflow policy: [`packages/fixed`](packages/fixed) and
[`docs/DESIGN.md`](docs/DESIGN.md). Compatible with Cairo 2.19.4.

## Why another fixed-point scalar

Every design choice is measured in Cairo steps and Sierra gas. Add, subtract and compare are one
native `i64` libfunc each; a product is an exact raw `i64` multiplication, and the fused kernels
sum raw products and rescale each output scalar once. Results are bit-exact: rounding is part of
the API, and any change of a numeric result is a MINOR version bump.

## Development

```bash
asdf install          # scarb + starknet-foundry from .tool-versions
scripts/check.sh      # fmt, lint, build, tests, gas snapshot check, docs
scripts/bench.py run  # net gas / steps / builtins per benchmark
```

Every function ships with a benchmark; `gas/*.snap` is committed and CI fails on any unreviewed
gas change. Contributor and agent rules: [`AGENTS.md`](AGENTS.md). Design:
[`docs/DESIGN.md`](docs/DESIGN.md). Changes: [`CHANGELOG.md`](CHANGELOG.md).
